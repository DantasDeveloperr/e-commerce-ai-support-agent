# E-commerce AI Support Agent

Agente de atendimento para e-commerce baseado em Large Language Models (LLMs).

## Objetivo

Este projeto tem como objetivo desenvolver um agente de IA capaz de interpretar solicitações de clientes, fornecer respostas contextualizadas e, posteriormente, utilizar dados e ferramentas para auxiliar no atendimento.

O projeto também será utilizado para explorar conceitos de:

- Large Language Models (LLMs)
- Agentes de IA
- RAG (Retrieval-Augmented Generation)
- Análise exploratória de dados (EDA)
- Avaliação de modelos de IA
- Machine Learning

## Tecnologias

- Python
- Pandas
- Scikit-learn
- LLMs
- Git e GitHub
